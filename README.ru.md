Современной краже аккаунтов не нужен вирус, который знает ваш антивирус. Вор читает базу
cookie браузера или запускает Chrome с отладочным портом и забирает cookie уже
расшифрованными, а архив отправляет боту в Telegram. Это занимает секунды, и ничего
«вредоносного» на диске не остаётся.

CookieGuard делает работу антивируса: проверяет файлы, держит сторожа в реальном времени,
ведёт карантин и фильтрует сеть. Сверх этого он стережёт каждый путь к вашим cookie и
паролям. Он отвечает не только на вопрос «известен ли этот файл как вредный», но и на
другой: **кто тронул cookie, как, когда и куда данные ушли потом**.

## Что умеет

| | |
|---|---|
| 🛡️ **Сторож в реальном времени** | Работает от SYSTEM с момента загрузки, без окна, даже пока никто не вошёл. Отдельный наблюдатель поднимает его в течение минуты, если сторожа убили. |
| 🍪 **Аудит cookie и паролей** | Ядро Windows записывает каждую программу, открывшую `Cookies`, `Login Data`, `Local State` или `key4.db`, во всех профилях всех браузеров: программа, PID, командная строка, точное время. |
| 🕵️ **8 агентов-усов** | Аудит файлов, приманки, отладочный порт, ключ шифрования, теневые копии, внедрение в браузер, сеть, `hosts`. Каждый агент отмечается на перекличке; молчание агента — тоже тревога. |
| 🪤 **Профили-приманки** | Ненастоящий `Profile 99` в каждом браузере. Браузер его не открывает, а вор, перебирающий профили, открывает — и попадается. |
| 🌐 **Контрольные точки сети** | 10 проверок на соединение: подпись, издатель, папка, имя в DNS, подмена в `hosts`, каналы слива (Telegram API, вебхуки Discord, файлообменники), прокси, возраст файла, VirusTotal, доверие. |
| 🔎 **Проверка файлов и архивов** | Бросьте файл, папку или архив в окно. Программа распакует архивы, в том числе вложенные и под паролем, и проверит их **~70 движками** через VirusTotal. Наружу уходит только отпечаток SHA-256, сам файл — никогда. |
| 🧭 **Эталон системы** | Снимок ~200 точек закрепления (автозапуск, расширения, сертификаты, прокси, службы, исключения антивируса) и точный список того, что изменилось с тех пор, как всё было чисто. |
| 🧰 **«Исправить всё» с откатом** | Один список всего, что можно исправить. Каждое изменение обратимо через `undo\`. |
| 🔒 **Карантин и завершение** | Карантин с побайтовым возвратом, завершение и обезвреживание процессов; по желанию — автокарантин файлов с 5+ детектами. |
| 🚫 **Свой блокировщик рекламы** | Расширение для Chrome, Edge и Brave. Списки на выбор: EasyList, EasyPrivacy, AdGuard, Fanboy или свой адрес. Обновляется само и в сеть не ходит. |
| 🧱 **Безопасный DNS** | Фильтрующий DNS (вредоносное, фишинг, реклама) включается и выключается одной кнопкой. |
| ♻️ **Самовосстановление** | Раз в минуту каждая часть защиты проверяется и включается обратно, если её выключили; само выключение — тоже тревога. |

## CookieGuard и обычный антивирус

| | Обычный антивирус | **CookieGuard** |
|---|:---:|:---:|
| Проверка файлов по базе вредоносного | свой движок | ✅ ~70 движков через VirusTotal, только отпечаток |
| Сторож в реальном времени | ✅ | ✅ служба SYSTEM + наблюдатель |
| Карантин | ✅ | ✅ обратимый, побайтово |
| Фильтрация сети и рекламы | платный модуль | ✅ встроена, списки на выбор |
| **Какая программа открыла базу cookie** | — | ✅ аудит ядра, с командной строкой |
| **Кража через отладочный порт (обход защиты Chrome 127+)** | редко | ✅ |
| **Профили-приманки** | — | ✅ |
| **Слив cookie через Telegram, Discord, файлообменники** | — | ✅ |
| **Разбор каждого корневого сертификата: может ли он читать HTTPS** | — | ✅ |
| **Проверка расширений браузера по магазину** | — | ✅ |
| **Сверка всей системы с эталоном** | — | ✅ |
| **Изменения `hosts` построчно и кто их сделал** | частично | ✅ |
| Отправляет ваши файлы в облако производителя | часто | **никогда** |
| Правила можно прочитать | закрытые сигнатуры | ✅ текстом в `lib\` |
| Цена | подписка | **бесплатно, MIT** |

**Правила, а не сигнатуры.** Сигнатура ловит только то, что кто-то уже видел. Правила
CookieGuard описывают *поведение*: «базу cookie открыла программа, которая не браузер»,
«браузер запущен с портом отладки», «неподписанный процесс только что соединился с Telegram
API». Без этого ничего не украсть — поэтому попадается и совсем новый вредонос.

CookieGuard работает рядом с вашим антивирусом (Defender, ESET, Kaspersky и другими) и не
спорит с ним.

## Установка

1. Скачайте [последний выпуск](https://github.com/SpawRon/CookieGuard/releases/latest) (или **Code → Download ZIP**) и распакуйте.
2. Запустите **`Setup.cmd`** и подтвердите запрос прав администратора.
3. Откройте CookieGuard из меню «Пуск» → **Защита** → включите **Автозащиту**.

Программа ставится в `C:\Program Files\CookieGuard`, куда процесс без прав администратора
писать не может, а данные держит в закрытой папке `C:\ProgramData\CookieGuard`.

**Нужно:** Windows 10 или 11, встроенные PowerShell 5.1 и .NET Framework 4.x. Больше ничего, никаких
сторонних библиотек.

**Без установки:** распакуйте куда угодно и запустите `CookieGuard.exe`. Все данные останутся
рядом с программой.

**Обновление:** **Защита → Версия программы → Обновить**. Берётся ветка `main` этого репозитория
по HTTPS; из архива ничего не запускается, ваши данные не трогаются. Расширение-блокировщик
обновится само вслед за программой.

**Удаление:** *Параметры → Приложения → CookieGuard* или `scripts\Uninstall.ps1`. Журналы и улики
остаются, если не добавить `-RemoveData`.
